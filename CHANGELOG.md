# Changelog

## 2.0.0 — Initial public release

- Released Neuro Granny, an offline Android app for practicing recall of passwords, PINs and access codes.
- Added fixed and adaptive review schedules, reminders, recall history and procedural visual cues.
- Added recoverable secret storage and salted Argon2id verify-only storage.
- Added local database import/export and safeguards against overwriting memories with duplicate titles.
- Made password changes and review-history reset atomic.
- Added eight interface languages and Android 6.0 (API 23) support.
- Published project-owned source and assets under the MIT license.
